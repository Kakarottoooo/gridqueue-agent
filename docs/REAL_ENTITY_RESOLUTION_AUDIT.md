# Real Entity-Resolution Audit

The real ERCOT entity-resolution audit is generated by:

```powershell
python scripts/run_real_ercot_pair.py --from-file data/raw/real/ercot/gis/ERCOT_GIS_2026_04.xlsx --from-snapshot-date 2026-04-30 --to-file data/raw/real/ercot/gis/ERCOT_GIS_2026_05.xlsx --to-snapshot-date 2026-05-31
```

Outputs:

- `reports/real_data/entity_resolution_audit/ercot_matches_2026_04_to_2026_05.csv`
- `reports/real_data/entity_resolution_audit/ercot_ambiguous_2026_04_to_2026_05.csv`
- `reports/real_data/manual_review/ercot_manual_review_template_2026_04_to_2026_05.csv`

The CSV distinguishes system labels from human labels. `auto_verified_exact_id` means the same ERCOT INR appeared in both snapshots; it does not mean a human reviewer verified the match. Human review only exists when `manual_label`, `manual_reviewer`, and review notes are filled by a person.

Allowed manual labels:

- `same_entity`
- `different_entity`
- `true_new`
- `true_removed`
- `true_withdrawn`
- `true_completed`
- `reclassification`
- `ambiguous_needs_review`
- `insufficient_evidence`

Recommended hand-label workflow:

1. Open the manual review template.
2. Label 20 to 50 high-materiality or non-exact cases first.
3. Do not label from the digest alone; compare project name, INR, county, fuel, capacity, status, COD, and source hashes.
4. Re-run `python evals/run_real_evals.py`. The human-label eval stays `skipped_manual_review` until manual labels exist.
